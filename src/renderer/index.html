Settings

Connection

Required token scopes

  • davis-copilot:conversations:execute Chat with Dynatrace Intelligence.

Additional scopes for data mode

  • davis-copilot:nl2dql:execute Turn questions into DQL queries.
  • storage:buckets:readRequired for all Grail queries.
  • storage:events:readProblems and events.
  • storage:logs:readLogs.
  • storage:metrics:readMetrics (timeseries).
  • storage:spans:readTraces and spans.
  • storage:entities:readEntities (hosts, services...).
  • storage:smartscape:readSmartscape topology.
  • storage:bizevents:readBusiness events.
  • storage:user.events:readReal user monitoring events.
  • storage:user.sessions:readReal user monitoring sessions.
  • storage:security.events:readSecurity events.
  • storage:system:readSystem events (workflows, audit).

Create a platform token in Dynatrace under Account Management > Identity & access management > Platform tokens. The token owner also needs a policy that allows Davis CoPilot / Dynatrace Intelligence conversations, and Dynatrace Intelligence must be enabled for the tenant.

Data mode

Free-text questions use environment data when this is enabled. Frontend health check buttons always run a query, even when this option is off. Query results are sent to Dynatrace Intelligence and may contain sensitive values.
